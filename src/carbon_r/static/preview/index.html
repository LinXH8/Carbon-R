Carbon R

Three design directions, built as previews before the main page changes.

Directions

A · Minimal
A report page. Warm paper, ink, a serif figure, hairline rules and no shadows. Caveats are set at body size behind an amber rule.
B · Soft
Calm through softness. A sage ground, nested double-bezel cards, diffuse depth, and provenance as a grid of readable tiles.
C · Workpaper
An auditor's schedule. Inputs on the left, record on the right. Ruled totals, lettered sources, numbered notes, and it prints.
D · Basalt
Dark-first, from a basalt photograph. The rock is the masthead only and fades into a charcoal page. Figures, sources and caveats sit on solid panels, never on the image.
E · Graphite
Basalt without the photograph. A graphene lattice, graphite grain and metallic sheen, all drawn in code, so nothing needs a licence. Same solid panels for every figure.
F · Anthracite
Dark only, set on a slate photograph (Annie Spratt, Unsplash License) that fills the page behind a light scrim. Figures, sources and caveats stay on solid panels.

Data

Every page runs live against /upload and /chat/stream. Add ?sample=electricity, fuel or flagged to replay a turn from sample.json, which scripts/build_ui_sample.py produces by running the real calculate_emissions and figure audit on the offline test fixtures.
